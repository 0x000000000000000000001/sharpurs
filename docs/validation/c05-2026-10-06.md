# C05 — shared focused-suite mechanics — 6 October 2026

**Validated: 70/100 points (70%), five of eight cycle-3 passes complete.**

## Scope and implementation

Six suites now use the common checked process helpers:
`adt-kernel`, `adt-interop`, `adt-unary`, `constructor-typeapp`, `int-comparison`
and `ffi-support`. Their six local command implementations and five current-runtime
Aff bridges are removed. The three remaining ADT Builder implementations are
replaced by `optimizeCoreFn`; constructor-TypeApp also routes its **current**
compiler through that helper. Int comparison uses `readCoreFn`.

The historical constructor collector/configuration/loader remains byte-identical
and uses its own runtime constructors, `old.Aff.monadAff` and
`old.Adt.prepareUnary`. The FFI differential adapter also remains suite-owned.
The suites still own all mutations, recognizers, JavaScript/generic oracles,
constructor registries and F# assembly decisions.

[`fixtures.mjs`](../../tests/support/fixtures.mjs) now owns the temporary-directory
lifecycle and guarded cwd scopes. [`corefn.mjs`](../../tests/support/corefn.mjs)
uses the cwd scope for the current Builder, including relative workspace paths.
Optimization must report every requested callback exactly once.

- Commands preserve their arguments and timeouts: 60 seconds for fixture compilation
  and FSI, 120 seconds for FFI's mixed-project `dotnet run`, with the same FSI options.
- Success removes the temporary and publishes `validation.log` when requested.
- Failure publishes the entire workspace under the requested artifact directory
  before removing the temporary. Without a destination it retains the temporary
  and prints its absolute path. The workspace includes any assembled program reached.
- Cwd is restored before publication/cleanup. Failed publication retains the
  original workspace and original suite error; publication failure after successful
  execution still returns failure.

The [testing guide](../testing.md#shared-focused-test-support) documents the
lifecycle and explicit cleanup of a retained failure directory.

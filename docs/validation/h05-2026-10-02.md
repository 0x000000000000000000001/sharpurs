## CLI changes

[`Sharpurs.CLI`](../../src/Sharpurs/CLI.purs) owns pure argument parsing, help and
the typed `Config { mainModule, ffiDirectory }`. `Main` removes Node's two argv
entries, handles help/errors, then passes `Compile Config` into the measured
compilation pipeline. PBO still provides TAST loading and directives.

The supported options are `--main`, `--ffi`, and `--help`/`-h`. The default module
is `Main`. Valued options accept separate values or `--name=value`; they must be
nonempty and may appear only once. Only the first equals sign separates a name
and value. Spaces, Unicode and subsequent equals signs are preserved. A final
empty `--` is accepted; positional arguments are rejected.

Usage errors exit **2**, with a diagnostic and usage hint on stderr, before
generation. Help exits **0** with stdout only and no project I/O. The complete
argument list is validated even when help is present. Compilation failures retain
exit **1**. Unknown options and the formerly ignored PBO flags `--bundle`,
`--output`, `--rewrite-limit` and `--autoload-path` now fail explicitly.

The [README migration](../../README.md#compiler-options) replaces a packed Spago
argument string with a YAML `backend.args` array or repeated `--backend-args`,
one token per argument. Both forms are tested with real Spago. Input/output
directories and the optimizer rewrite limit retain their documented fixed values.

## Implementation

[`tests/support/packages.mjs`](../../tests/support/packages.mjs) is the single
resolution owner, re-exported by `fixtures.mjs` for existing callers. The five
duplicated searches now call that same API.

- The resolved top-level `packages` entry in JSON `spago.lock` selects an exact
  registry version or a local path. `workspace.packages` supports workspace-owned
  sources. A collision between the two maps fails with an ambiguity diagnostic.
- Registry paths are exactly `.spago/p/NAME-VERSION/src`; local/workspace paths
  resolve relative to the backend and append `src`. The selected path must exist
  and be a directory before compilation starts.
- An explicit `{ source }` wins first, then `PRELUDE_SRC` for Prelude. Explicit
  paths support spaces, are validated, and are made absolute from the caller's cwd.
  Source kinds such as Git can use that explicit-directory API.
- Without a resolved entry, the helper requests a workspace build or explicit
  source. It diagnoses malformed metadata, missing locked sources and ambiguity
  instead of selecting a cached release. Cache enumeration serves diagnostics only;
  candidate names are exact-package version suffixes and sorted for stable output.

The [testing guide](../testing.md#deterministic-fixture-dependencies) documents the
contract, commands, precedence and migration of cache-only setups to a prepared
lockfile or explicit source. Suite assertions, recognizers and oracle construction
retain their existing implementations.

## Test changes

[`tests/support/ast.mjs`](../../tests/support/ast.mjs) replaces all **nine** local
prototype-preserving clone implementations. It supplies named, checked access to
source bindings, optimized binding tuples, annotations, lambda parameters,
application heads/arguments and data declarations. Named views update the actual
selected nodes; raw constructors remain available through `.node`.

Binding lookup requires exactly one match. Lambda/application selectors verify
the expected arity and stop at explicit boundaries such as `TypeApp`. First-node
selection fails with a labelled diagnostic when its constructor/predicate target
is absent. Negative mutation helpers additionally verify that their copied tree
was actually changed before asking the production recognizer to reject it.

The shared support imports runtime constructors, not production recognizers.
Suites retain eligibility decisions, mutation labels, native/generic/JavaScript
oracles and historical compiler adapters. The constructor-TypeApp suite still
owns its deliberate traversal across erased type applications. Its historical
collector/configuration/loader adapter is byte-identical to the H05 version.

**21 F# fixture files** now hold static support and runtime programs. The nine
mutation-heavy suites use these files, as do local Int kernels, recursive code,
case patterns and the printer's static support. Selection tests use the checked
source-call views. The main examples are
[`direct-call.mjs`](../../tests/direct-call.mjs),
[`int-arithmetic.mjs`](../../tests/int-arithmetic.mjs) and
[`adt-multi.mjs`](../../tests/adt-multi.mjs).

[`tests/support/fsharp.mjs`](../../tests/support/fsharp.mjs) loads fragments
relative to the maintained fixture directory, independently of process cwd.
Named insertion slots must occur exactly once: missing, repeated and unused slots
fail before FSI. Each suite explicitly assembles generated code and its oracles
around its static fragments. The new
[`fixture-support` suite](../../tests/fixture-support.mjs) guards these contracts.
The [contribution guide](../testing.md#contributing-a-structural-mutation) explains
live views, target assertions, historical constructors and F# insertion points.

# C02 — shared subprocess lifecycle for modtest — 5 October 2026

**Validated: 25/100 points (25%), two of eight cycle-3 passes complete.**

## Characterized behavior

The original `modtest` forwarded SIGINT/SIGTERM to its active process group, but
did not escalate or finish cancellation when the direct child exited before its
descendants. Eight isolated cases reproduced the consequences: interrupt a build
or a module with either signal, with the active phase either exiting or ignoring
the signal, while a descendant ignores both signals. The original runner left
descendants alive; the two resistant direct-module cases also exceeded the
harness's eight-second deadline.

The historical run passed five of 14 tests and failed nine. Eight failures cover
that interruption matrix; the ninth is the new expectation for explicit `[PASS]`
lines, rather than a separate cancellation defect. Selection, help/listing, usage
errors, ordinary command failures and missing executables already passed.

## Implementation

[`scripts/support/process.mjs`](../../scripts/support/process.mjs) now owns
`runProcess`, used by both the live-output module runner and `runLogged`:

- A command owns its process group. Cancellation forwards SIGINT when requested,
  otherwise SIGTERM, escalates after two seconds if the direct child stays active,
  and kills remaining group descendants when cancellation closes that child.
- An already-aborted step launches no command. Results retain command tokens,
  exit/signal, error, timeout/cancellation flags, success and elapsed time.
- `runLogged` is the file-output adapter: complete stdout/stderr go directly to
  file descriptors, with the command header and spawn diagnostic retained. Its
  `finally` closes the log even if writing the header fails.

[`tools/modtest-runner.mjs`](../../tools/modtest-runner.mjs) owns selection and
presentation. It uses the shared process owner with inherited stdin/stdout/stderr,
prints `[PASS]` after each successful build/module, and stops on the first failed
dependent step. It retains explicit/default order, deduplication, inclusive resume
and its aliases, help/listing, exact arguments and one compiler build for `-c`.
Usage errors exit 2, command failures exit 1, and handled SIGINT/SIGTERM exit
130/143. Signal listeners are removed on completion.

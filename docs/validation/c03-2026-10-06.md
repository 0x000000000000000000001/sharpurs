# C03 — private native-library test workspaces — 6 October 2026

**Validated: 45/100 points (45%), three of eight cycle-3 passes complete.**

## Characterized behavior

The 19 native `bin/test` scripts had two contents, differing only in the final
success-message formatting. They removed `output`, `.spago` and `.cache` from
their own checkout and every `sharpurs-*` sibling, then replaced `spago.yaml`
with the selected Sharpurs profile. A failure could therefore leave unrelated
working outputs removed and the caller's previous profile lost.

The historical script was replayed only in isolated layouts, using five original
profile shapes (file, relative symlink, absolute symlink, dangling symlink and
absence) crossed with success and failures in Spago, Sharpurs and .NET. All 20
cases fail the new suite: 15 reach the checkout-preservation assertion; the five
.NET-failure cases first encounter the historical exit 7 versus the shared
runner's normalized exit 1. The latter difference is an exit-code change, not an
additional cleanup defect. Historical logs and command traces are retained.

## Implementation and ownership

All 19 executable wrappers now contain the same four lines and delegate to
[`tools/native-test-runner.mjs`](../../tools/native-test-runner.mjs). That runner
owns preparation, profile selection, compiler/module phases and finalization:

- Each invocation creates its own `mkdtemp` workspace and snapshots the available
  sibling input layout, including untracked maintained inputs, native FFI,
  lockfiles and local dependency overrides. Links are materialized as copies.
  Checkout output/cache trees, Git metadata and npm dependencies are excluded.
- Only the selected module's **copied** profile is switched, retaining priority
  `spago.sharp.yaml`, `spago.fs.yaml`, then the existing `spago.yaml`. The original
  profile, its target and neighboring checkouts remain untouched by the run.
- The normal path copies the installed compiler bundle/wrapper and native `bak`
  overrides. A direct native `-c`/`--clean` copies the compiler sources and its
  external PBO dependency too, then uses the shared build/bundle steps privately.
  `modtest -c` keeps its established one-time installed-compiler build contract.
- Module phases retain `spago build`, `--main Test.Main`, F#-before-C# project
  selection, and the Release .NET command arguments. A failed preparation or phase
  stops dependent commands; an old project cannot satisfy a missing generation.
- Successful temporary workspaces are removed. Failure/interruption retains the
  workspace and `results.json`; `SHARPURS_NATIVE_ARTIFACTS` retains successful
  workspaces under unique children of a chosen evidence parent as well. Output is
  inherited live. Reporting/cleanup failure prevents a successful exit/message.

The native runner uses the existing `runProcess` owner. `modtest` grants its native
child five seconds before escalation, allowing the inner owner's two-second
escalation to terminate resistant descendants and finish reporting. Other callers
keep the two-second default. Nested cancellation is verified through the actual
public wrappers, rather than only mocking a module process.
